# Размещение Day: варианты на 21 ноября 2026 года

Day использует серверные API и auth callback, поэтому нужен серверный Next.js с HTTPS. Обычный статический хостинг не заменяет сервер приложения. Supabase остаётся отдельным сервисом данных и приватных фотографий.

| Вариант | Зарубежная площадка | Цена в месяц | Оплата и ограничения |
| --- | --- | --- | --- |
| [ИХЦ EU-NVMe/2](https://www.ihc.ru/vps-netherlands.html) | Нидерланды | 1 140 ₽; 1 CPU, 2 ГБ RAM, 30 ГБ SSD | [МИР для серверов в Европе](https://www.ihc.ru/vps-mir-card.html) |
| [ИХЦ EU-NVMe/4](https://www.ihc.ru/vps-netherlands.html) | Нидерланды | 1 890 ₽; 2 CPU, 4 ГБ RAM, 45 ГБ SSD | Больше запаса для сборки Next.js; это рекомендация по ресурсам, не гарантия производительности |
| [Timeweb Cloud NL-30](https://timeweb.cloud/services/vds-vps?location=nl) | Нидерланды | 1 760 ₽; 1 CPU, 2 ГБ RAM, 30 ГБ NVMe | [Карты и СБП](https://timeweb.cloud/docs/service-payments/payment-methods); [IPv4 оплачивается отдельно](https://timeweb.cloud/docs/public-ip) |

Для небольшого публичного запуска с оплатой рублями предлагается ИХЦ EU-NVMe/4: запас памяти полезен, если сборка выполняется на том же VPS. Для личного теста подойдёт Vercel Hobby в пределах его условий и квоты. Цены проверены по официальным страницам; наличие тарифа и итоговую сумму с дополнительными услугами нужно посмотреть в форме заказа перед оплатой.

Ничего не куплено и не опубликовано. Следующий шаг после выбора — создать сервер, настроить домен/HTTPS, перенести серверные секреты, собрать артефакт и добавить точные production callback URL в Supabase/Google. Инструкция проверки: [release.md](release.md). Резервные копии, мониторинг и обновления VPS требуют обслуживания.
