# Day: animated daily closure

Replace the compact review form with an immersive accessible multi-step screen in the existing application. User explicitly requests animated statistics, optional transfer of unfinished tasks to tomorrow/another date, five-star day rating, free-text review and hold confirmation. User confirmed closed reviews remain editable and transfers must never repeat on edits. Preserve Day's monochrome theme and existing records.

## Experience
Full-screen Radix dialog with three stages: results, remaining tasks, rating/reflection. Real completed task titles, task completion percentage, habits, water and food totals; tasteful count/ring/progress transitions and staggered content. Respect reduced motion. Previous/next steps retain draft state; closing the dialog abandons the draft without task changes. Final stage shows pending transfer count/date and the supplied hold-to-confirm pattern with a real two-second callback, keyboard support and cancellation. Success screen explicitly confirms saved day and offers to return or view tomorrow.

Ark RatingGroup based on supplied component, controlled in src/components/ui/rating-group.tsx; half stars, Russian labels, black/white fills, no yellow. Rating0 means no rating; note up to2000 characters is optional. Hold component in src/components/ui/motion-hold-to-confirm.tsx uses supplied Motion progression/ring design but neutral colors and an actual onConfirm callback. It must cancel on release/leave/cancel/blur/hidden/unmount and never fire twice. Keyboard Space/Enter can be held; no key repeat reset. Reduced motion keeps confirmation duration but suppresses scaling/movement. Existing TS/Tailwind/shadcn aliases already configured; no image assets needed.

## Data
Extend DayReview with optional rating (0..5 in0.5 steps), closedAt, immutable snapshot and transfer log. Existing mood/note/updatedAt stay valid. Old reviews remain readable and can be closed in new flow. Closing is one validated AppData update: snapshot actual day before transferring, then move selected unfinished tasks, then save review. Existing cloud codec already round-trips all review fields via preferences JSON, so no SQL migration.

One-offs keep id and move due date. Repeating tasks exclude only source occurrence and create a separately identified one-off copy at destination; future series occurrences remain independent even if destination already has the recurring task. Task.excludedDates is optional for backward compatibility. Preserve it when editing the series. Past selected day may be reviewed, but transfer destination must be after both selected day and actual today; default is tomorrow from today. No automatic completion/deletion. Completed/deleted tasks at commit time are ignored safely, not resurrected. Reopening a closed review changes rating/note only, retaining snapshot/closedAt/log and never transferring again. Transferring tasks during an active focus invalidates that focus through existing eligibility guards.

## Constraints and verification
No user data seeded on localhost:3000. No remote publishing or live cloud claims. Meaningful red/green tests for schema migration, recurring transfer, snapshot/idempotency, stale tasks, keyboard rating, interrupted hold and callback-once, draft/step/close behavior. Serial full suite, lint, TypeScript, build; isolated production browser desktop/mobile proof including actual2s hold and short-release cancellation. Do not overlap full suite/build due observed host memory pressure. No Git repository/worktree.
