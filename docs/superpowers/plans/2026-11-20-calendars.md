# Day calendars implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Track work below.

**Goal:** Обновить календарь главной и планировщика, добавить фотографии дней и календарь продуктивности.
**Architecture:** Клиентские компоненты используют существующий DayProvider, I18nProvider, taskOnDate/taskDone и локальное фотохранилище. Фотографии дат привязаны к аккаунту, статистика берётся из задач или снимка закрытого дня.
**Tech Stack:** Next 16, React 19, TypeScript, Tailwind 4, motion/react, lucide-react, IndexedDB.
**Spec:** docs/superpowers/specs/2026-11-20-calendars-design.md

## Global constraints
- Сохранить пользовательские изменения авторизации, данные и предпочтения.
- RU/EN/IT, адаптивность, клавиатура, reduced motion.
- Никаких фиктивных задач/сессий в рабочих экранах или новых зависимостей.

## Review focus
- Високосный год, переход декабря/января, локальная дата без UTC-сдвигов.
- Повторяющиеся/исключённые задачи, закрытые дни после переноса.
- Нет задач и будущие даты не получают красную оценку.
- Фото: ошибка записи, смена аккаунта/сброс во время загрузки, старые backup.
- Мобильный год без неконтролируемого горизонтального переполнения.
