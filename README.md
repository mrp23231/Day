# Day

Русскоязычное веб-приложение для планов, питания и заботы о себе. Next.js App Router, React, strict TypeScript, Tailwind CSS, Radix/shadcn-style primitives, Motion, Lucide, Recharts, Zod и Supabase.

## Запуск

Требуется Node.js 20.9+.

```sh
npm ci
npm run dev
```

Откройте http://localhost:3000. Для production:

```sh
npm run build
npm start
```

## Что работает без ключей

- «Сегодня»: приветствие, круг выполнения задач, важные/активные/завершённые дела, ближайшая задача со временем, отдельный список прошлых разовых дел. Быстрый ввод по Enter, выбор даты, привычки, вода и питание. Прогресс задач независим от воды и питания; общая сводка остаётся в «Моём прогрессе».
- Планировщик: добавление, редактирование, удаление, выполнение, время, приоритеты, категории, описание, повторение по дням/будням/неделям, поиск и фильтры; дневной, недельный и месячный вид.
- Питание: дневник с четырьмя приёмами пищи, порциями и БЖУ; редактирование, удаление, избранное и повтор блюда; простой/продвинутый режим.
- Детерминированный калькулятор по формуле Миффлина — Сан Жеора для взрослых, объяснение расчётов и ручные ориентиры. Неподдерживаемые результаты нельзя автоматически применить.
- Вода: быстрые и произвольные порции, история, удаление, изменяемый ориентир и недельный график.
- Привычки: создание, изменение, удаление, расписание, отметки по датам, недельная история и серии.
- Прогресс: графики задач, питания, воды и привычек за день/неделю/30 дней; БЖУ в продвинутом режиме. Никакой вымышленной истории.
- Имя, знакомство с приложением, системная/светлая/тёмная тема с плавным раскрытием, четыре сохраняемых фона, экспорт и восстановление JSON с предпросмотром и подтверждением замены, предыдущая локальная копия и очистка записей с подтверждением.
- Общий поиск по задачам, привычкам и питанию за все даты, переходы между разделами и быстрые команды создания записей. Открывается кнопкой в шапке или ⌘K / Ctrl+K; стрелки выбирают результат, Enter открывает, Escape закрывает. Поиск работает локально.
- Фокус: одна незавершённая задача на сегодня, обратный отсчёт до её времени и таймер работы от 5 до 120 минут. Запуск по решению пользователя, пауза/продолжение, досрочное завершение задачи и компактная панель между разделами. Сессия хранится отдельно для гостя/аккаунта; время считается по отметкам часов, а не числу срабатываний интервала. После закрытия приложения таймер не отправляет push; при возвращении пересчитывает остаток. Устаревшие сессии старше суток не восстанавливаются.
- Личные фотографии для фона, навигации и каждого блока главной: локальная загрузка JPEG/PNG/WebP/AVIF до 20 МБ, уменьшение до 2000 px, удаление исходных метаданных и хранение в IndexedDB текущего браузера отдельно для гостя/аккаунта. Чёрно-белый или исходный цвет, замена/удаление. Фотографии не передаются на сервер и не входят в JSON/облачную копию; на другом устройстве их нужно выбрать снова. Доступны порядок и видимость блоков, минимум один остаётся на главной.
- Редактирование главной на месте: удержание свободной области блока около 0,55 с или кнопка «Настроить главную». Перетаскивание, лёгкое покачивание, клавиатурные ручки и стрелки, скрытие/возврат блоков. «Изменить» открывает выбор фото, замену/удаление и цвет; нижняя панель предлагает фото фона/навигации и «Готово». Порядок сохраняется после отпускания, отменённые жесты его не меняют. Новое фото плавно проявляется после загрузки.
- Разноцветные шарики при выполнении последней задачи: короткая анимация десяти небольших элементов без тяжёлых SVG-фильтров. Эффекты не накладываются, очищаются и учитывают уменьшение движения.
- Закрытие выбранного дня в три этапа: анимированные итоги по реальным задачам, привычкам, воде и питанию; необязательный перенос каждой выбранной незавершённой задачи на завтра или свою дату; оценка дня и заметка. Оценка необязательна: 0–5 с шагом 0,5, где 0 означает отсутствие оценки; заметка — до 2000 символов. Сохранение и перенос происходят после двухсекундного удержания кнопки указателем либо клавишей Enter/Space. Снимок итогов сохраняет статистику до переноса. У закрытого дня можно менять оценку и заметку; повторное открытие не переносит задачи снова. Итоги включены в JSON и явную облачную копию; старые данные v1 остаются совместимыми.
- Уведомления Ding React с анимацией, светлой/тёмной темой Day и действиями: например, отмена добавленного стакана воды. Это обратная связь внутри приложения, а не системные push-уведомления.
- Мобильная плавающая панель «Сегодня / Календарь / Добавить / Привычки / Профиль», адаптивная боковая навигация, клавиатурный фокус, Radix dialogs, reduced motion, PWA manifest и иконки.

В профиле можно восстановить записи из JSON до 10 МБ: сначала сводка, затем подтверждение замены. Текущая версия сохраняется в предыдущую локальную копию; её можно скачать и импортировать для отката. Фото и завершённое знакомство этого устройства остаются прежними. JSON не содержит самих фотографий. Импорт не сохраняет новую облачную копию автоматически.

По умолчанию записи хранятся в `localStorage` текущего браузера. Приложение начинает с пустых данных. Локальное пространство и каждый аккаунт имеют отдельные ключи хранения. Удаление данных сайта в браузере удалит локальные записи — используйте экспорт.

## Подключение Supabase

1. Создайте Supabase-проект, скопируйте `.env.example` в `.env.local` и заполните `NEXT_PUBLIC_SUPABASE_URL` и `NEXT_PUBLIC_SUPABASE_ANON_KEY` публичным ключом проекта.
2. Через официальный Supabase CLI свяжите проект и примените миграцию:

   ```sh
   npx supabase login
   npx supabase link --project-ref YOUR_PROJECT_REF
   npx supabase db push
   ```

3. В Auth URL Configuration задайте Site URL и разрешённые redirect URL для `http://localhost:3000/auth/callback` и `http://localhost:3000/auth/callback?recovery=1` (для размещённой версии замените origin). Разрешите email/password auth и настройте доставку писем. Используется стандартный PKCE-процесс Supabase.
4. Для удаления аккаунта заполните **только на сервере** `SUPABASE_SERVICE_ROLE_KEY`. Без него удаление сообщает о недоступности.
5. Для Google включите провайдер Google в Supabase Auth и добавьте Client ID/Client Secret веб-приложения из Google Auth Platform. В Google Authorized redirect URIs укажите callback Supabase из его панели, а в Supabase Redirect URLs — адрес приложения `/auth/callback`. Google Client Secret хранится у провайдера Supabase и не добавляется в клиентский код. [Официальная настройка Google](https://supabase.com/docs/guides/auth/social-sign-in/auth-google).
6. Перезапустите Next.js. В профиле доступна кнопка «Создать аккаунт» с выбором Google/email, а также email-вход и восстановление пароля. После первого входа запускаются три шага знакомства: необязательное имя/псевдоним, фокус и ритм дня; затем персональное приветствие. Знакомство гостя не пропускает знакомство с новым аккаунтом. Прогресс завершения хранится в настройках текущего пространства, включается в явную облачную копию и не переносит гостевые записи в аккаунт. Повторить или завершить знакомство можно в профиле. Старые локальные/облачные записи совместимы; перед первым показом ожидается загрузка аккаунта.

Облачные копии сохраняются **явно кнопкой**, а не автоматически. RPC атомарно сохраняет пользовательские записи; номер ревизии отклоняет устаревшую запись с другого устройства. Если возник конфликт, сначала экспортируйте локальную копию, затем восстановите нужную облачную копию и перенесите изменения вручную. Автоматическое слияние не реализовано. Вход/перезагрузка не заменяет существующий локальный черновик более старым облачным снимком.

Миграция создаёт профили, задачи и повторения, цели питания, приёмы пищи и ингредиенты, воду, привычки и отметки, настройки и квоты AI. RLS ограничивает каждую таблицу владельцем, составные внешние ключи не позволяют связывать данные разных владельцев. Личные фотографии оформления сохраняются только локально в IndexedDB, поэтому Supabase Storage bucket не требуется. Данные итогов — оценка, заметка, время закрытия, снимок статистики и журнал переносов — проходят сохранение и восстановление через существующий RPC в JSON-настройках (`dayReviews`), валидируются и возвращаются в `AppData.reviews`; новая SQL-миграция не нужна.

## Подключение OpenAI

После настройки Supabase заполните серверный `OPENAI_API_KEY` и при необходимости `OPENAI_MODEL` (по умолчанию `gpt-4.1-mini`). Ключи не должны иметь префикс `NEXT_PUBLIC_`. Сервер использует Responses API с `store: false`; фото распознаются через Structured Outputs с последующей Zod-проверкой. Запросы требуют аутентификации и ограничены PostgreSQL-квотой: 10 запросов за 10 минут на пользователя.

Day AI отмечен как бета: доступны текстовые советы и предложения плана, создание задач, голосовой ввод и фотографии в чате обозначены как будущие возможности. Поле ввода разворачивается при фокусе, растёт по тексту, Enter отправляет, Shift+Enter переносит строку; завершение IME не отправляет сообщение. При смене аккаунта/сбросе/выходе из раздела ожидающий запрос отменяется, история чата остаётся только в памяти текущего экрана. Ошибки сохраняют черновик для повтора. Day AI получает текст сообщения; дневная сводка добавляется только при выбранном флажке. Помощник не имеет инструментов изменения записей. Фотография передаётся OpenAI только после нажатия «Распознать», максимум 5 МБ; проверяются MIME и сигнатура файла. Результат содержит вероятные продукты, примерный вес и уверенность.

**Проверенная база пищевой ценности пока не подключена.** Распознанные продукты можно перенести в ручную форму, проверить и дополнить калориями и БЖУ. Приложение не выдаёт сгенерированные нутриенты за точные значения. Без ключей или при сбое сервисов отображается сообщение и остаётся ручной ввод.

Ближайшее дело — это просмотр времени в плане. Серверные напоминания, Web Push, отложенная доставка и разбор задач естественным языком пока не реализованы.

## PWA и offline

Устанавливается из поддерживающего PWA браузера на HTTPS или localhost. В production service worker сохраняет только публичные статические ресурсы и offline-страницу; API, auth и персональные данные не попадают в общий Cache Storage. Уже открытый экран работает с локальными записями без сети. Холодный запуск всех разделов offline и автоматическая облачная синхронизация offline не реализованы.

## Проверки

```sh
npm run verify
npm run release:check
```

`verify` последовательно запускает lint, тесты проверки конфигурации, весь Vitest в одном worker и production build с проверкой TypeScript. Отдельные команды `typecheck`, `lint`, `test`, `test:release` и `build` остаются доступны. Перед публикацией облачной беты выполните `npm run release:check -- --strict`: отсутствующие обязательные переменные дают код 1, значения ключей никогда не выводятся. Проверка читает production `.env`-файлы Next.js, но не подтверждает доступность внешних сервисов.

Порядок подготовки среды, live-проверок входа/RLS/AI, запуска и отката описан в [инструкции выпуска](docs/release.md). Настройте публичные Supabase-переменные до сборки; их изменение требует пересборки. Реальная публикация, домен, внешние сервисы и правила обработки данных — отдельные шаги перед доступом пользователей.

Unit/route tests проверяют формулы, дату и повторение, независимость отметок, серии, проверку данных, восстановление локального состояния, политики облачных гонок, безопасное применение целей и unavailable/validation paths API. Ручные проверки production-интерфейса описаны в `docs/qa.md`. Внешние Supabase/OpenAI интеграции требуют ваших ключей и отдельной live-проверки; успешное подключение без них не заявляется.

## Основания расчётов

- [Оригинальная формула Mifflin–St Jeor](https://pubmed.ncbi.nlm.nih.gov/2305711/).
- [Диетические референсные значения EFSA](https://www.efsa.europa.eu/en/topics/topic/dietary-reference-values).
- [Официальная документация Supabase SSR](https://supabase.com/docs/guides/auth/server-side/creating-a-client).
- [OpenAI Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs).

Поправки активности и целей, выбор белка 1,2–1,6 г/кг и 30% энергии из жиров — изменяемые продуктовые ориентиры, не индивидуальное медицинское назначение. Формулы могут не подходить при беременности, лактации, заболеваниях и расстройствах пищевого поведения. Для лиц младше 18 лет автоматический расчёт недоступен.
